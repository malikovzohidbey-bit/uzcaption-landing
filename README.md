## 🇬🇧 English

**UzCaption** is an AI subtitle generator specialized in **Uzbek speech recognition**.
You send a video, it transcribes the speech and returns subtitles.

### Where you can use it

| Channel | Link |
|---|---|
| Telegram bot | [@uzcaptions_bot](https://t.me/uzcaptions_bot) |
| Web editor (Ijodxona) | [caption.uz/ijodxona/](https://caption.uz/ijodxona/) |
| Adobe Premiere Pro plugin | [caption.uz/plugin](https://caption.uz/plugin) |
| iOS app | TestFlight beta |

### What you get

- A video with **burned-in captions**, or
- An **SRT file** for CapCut, Premiere Pro, DaVinci Resolve and other editors
- **27+ caption style presets**
- **Subtitle translation** into other languages
